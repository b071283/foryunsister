# foryunsister

推薦評價系統前端模板（為 yun sister 客製）。

## 預覽

- 正式網址：<https://sister.socialcontactapp.net>
- GitHub Pages 原始網址：<https://b071283.github.io/foryunsister/>
- 本機：直接開啟 `index.html`

## 結構

- `index.html` — 頁面骨架
- `styles.css` — 樣式（紫色淡雅風格）
- `script.js` — 多選 tag 互動與送出邏輯

## 部屬

推送到 GitHub 後，於 repo Settings → Pages 啟用 `main` branch 根目錄即可。

之後可透過 Cloudflare 設定 CNAME 指向 `<user>.github.io`，並在專案根目錄放置 `CNAME` 檔指定自訂網域。
